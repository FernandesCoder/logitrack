
# LogiTrack

**LogiTrack** é um sistema inteligente de controle de **combustível**, **quilômetros rodados** e **horas trabalhadas** para veículos, tratores e maquinários rurais. Ele foi desenvolvido para otimizar o controle de operações agrícolas, reduzir custos e melhorar a eficiência do transporte e máquinas utilizadas na fazenda.

## 🔧 Tecnologias Usadas

- **Backend**: Node.js, Express
- **Banco de Dados**: MongoDB
- **Outras Ferramentas**: Git, GitHub

## 🛠 Funcionalidades

- **Cadastro de veículos e máquinas** com informações detalhadas.
- **Controle de combustível** gasto por cada veículo.
- **Cálculo automático de quilômetros rodados** e **horas trabalhadas**.
- Relatórios diários, semanais ou mensais sobre os **custos operacionais**.
- Visualização de **gráficos** sobre o desempenho de cada veículo/máquina.

## 🌱 Como Rodar o Projeto Localmente

### Pré-requisitos

1. **Node.js** instalado (se não tiver, [faça o download aqui](https://nodejs.org/))
2. **MongoDB** rodando localmente ou com uma instância na nuvem (use [MongoDB Atlas](https://www.mongodb.com/cloud/atlas))

### Passos para rodar:

1. **Clone o repositório**:

```bash
git clone https://github.com/FernandesCoder/logitrack.git
```

2. **Entre na pasta do projeto**:

```bash
cd logitrack
```

3. **Instale as dependências**:

```bash
npm install
```

4. **Rodando o servidor**:

```bash
npm start
```

O servidor estará rodando na URL: `http://localhost:3000`
